# VeryFun Studio

VeryFun Studio 是一个独立拼图游戏工作室，为手机上的片刻闲暇，制作轻松、富有触感的小游戏。

[访问官网](https://veryfunstudio.github.io/) · [了解工作室](https://veryfunstudio.github.io/about/) · [联系](https://veryfunstudio.github.io/contact/)

## 三款精选，各有乐趣

从我们的 [Android 游戏作品](https://veryfunstudio.github.io/about/)中，挑选三种不同的乐趣。

[Nova Mahjong](#nova-mahjong-for-seniors) · [Tile Journey](#tile-journey) · [Arrow Out](#arrow-out)

### Nova Mahjong For Seniors

**放慢节奏，配对眼前的麻将牌。**

大而清晰的牌面，铺在绿毡上。不必赶时间，慢慢寻找下一对。

[了解游戏](https://veryfunstudio.github.io/games/nova-mahjong/) · [前往 Google Play](https://play.google.com/store/apps/details?id=com.veryfuncompany.mahjongjourney)

### Tile Journey

**找到三张相同的牌，享受消除的一刻。**

在层叠的 3D 牌块中寻找配对，离线也能探索色彩丰富的场景。

[了解游戏](https://veryfunstudio.github.io/games/tile-journey/) · [前往 Google Play](https://play.google.com/store/apps/details?id=com.veryfun.tilejourney)

### Arrow Out

**一步挪动，打开一条新路。**

观察箭头方向，找到畅通的出口，一步步清空棋盘。

[了解游戏](https://veryfunstudio.github.io/games/arrow-out/) · [前往 Google Play](https://play.google.com/store/apps/details?id=com.veryfuncompany.kittyescape)

<summary>关于预览与平台</summary>

这里展示三款精选游戏，并非工作室的全部作品。游戏预览来自官方产品页，保留原图；部分素材含宣传文字，并非本页重新拍摄的设备截图。顶部拼图插画是主页的装饰设计，不是可玩的游戏。
